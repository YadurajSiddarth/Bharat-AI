# BHARAT-AI: Development Roadmap

## Project Objective

Develop an Indian-centred multilingual AI ecosystem with strong global capabilities through research, experimentation and incremental engineering.

---

## Phase 0: Research Foundation and Environment Setup

**Status: Completed**

Objectives:
- Create the GitHub repository.
- Set up Python and the development environment.
- Install machine-learning dependencies.
- Verify PyTorch and Apple MPS.
- Establish project documentation and architecture.

Deliverables:
- Research repository
- Development environment
- Research vision
- Initial system architecture

## Phase 1: Multilingual Model Exploration

**Status: In Progress**

Objectives:
- Understand existing multilingual language models.
- Explore Hugging Face model architectures.
- Run inference using existing models.
- Test English, Kannada, Hindi and Malayalam.
- Investigate native-script, Romanised and code-mixed input.
- Establish an initial evaluation dataset.

Deliverables:
- Model comparison report
- First working inference experiment
- Multilingual evaluation dataset
- Initial performance baseline

## Phase 2: First BHARAT-AI Application

Objectives:
- Build a basic multilingual AI application.
- Develop a Python inference pipeline.
- Create a simple user interface.
- Integrate a selected language model.
- Introduce reliable response handling.

Deliverables:
- Working application prototype
- Basic API
- Initial user testing

## Phase 3: Knowledge and Retrieval Systems

Objectives:
- Learn document processing and embeddings.
- Implement Retrieval-Augmented Generation.
- Build a small, legally usable knowledge collection.
- Evaluate retrieval accuracy and answer quality.

Deliverables:
- Document ingestion pipeline
- Search and retrieval system
- Grounded response generation

## Phase 4: Model Customisation

Objectives:
- Study multilingual datasets and tokenisation.
- Explore parameter-efficient fine-tuning.
- Experiment with LoRA and QLoRA.
- Compare customised models against baseline models.
- Measure improvements and regressions across languages.

Deliverables:
- Fine-tuning experiments
- Model evaluation reports
- Reproducible training configurations

## Phase 5: Advanced Multilingual AI Research

Objectives:
- Investigate continued pretraining.
- Explore multilingual speech recognition.
- Explore speech generation.
- Improve dialect and code-mixed language understanding.
- Investigate cultural and regional context representation.

Deliverables:
- Advanced research prototypes
- Multilingual speech experiments
- Expanded evaluation benchmarks

## Phase 6: Long-Term Foundation Model Research

Objectives:
- Study transformer architecture and large-scale training.
- Investigate multilingual tokenisation and data mixtures.
- Estimate compute and infrastructure requirements.
- Evaluate whether training a model from scratch is justified.

Deliverables:
- Foundation-model research proposal
- Compute and data requirements
- Experimental training plan

---

## Evaluation Principles

Every phase should be evaluated using measurable criteria:

- Language understanding
- Response accuracy
- Reasoning ability
- Code-switching performance
- Native-script handling
- Romanised input handling
- Cultural and contextual appropriateness
- Safety and privacy

## Resource Strategy

Initial development will use:

- Apple MacBook Air M4 for for coding and lightweight experiments.

- Google Colab for GPU-based experiments when available.

- GitHub for version control.

- Open-source tools and models where licensing permits.

##Current Milestone

Complete Phase 1 by selecting a suitable multilingual model, running our first inference experiment and establishing a baseline across our initial languages.
